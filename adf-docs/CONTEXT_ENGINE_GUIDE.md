# Context Engine Guide

## Why

ADF’s first engine standardizes how every AI restores context. This guide is human-oriented; normative specs live under `.adf/CONTEXT_ENGINE.md` and `.adf/context/`.

## What It Is / Is Not

| Is | Is not |

| Shared restore workflow | GUI |
| Spec for all AIs | Executable runtime (yet) |
| Foundation for BUILD-005 | A new top-level package |
