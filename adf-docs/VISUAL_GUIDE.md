# Visual Guide

**Operator guide for Visual Intelligence.** BUILD-015.

## Open

1. Sidebar → **Visual**
2. Pick an overview card or catalog entry
3. Use layout buttons (force/tree/grid/hierarchical/radial)
4. Search/filter nodes; select nodes for inspector
5. Collapse focuses neighborhood of selection

## Accessibility

- Toolbar buttons are labeled
- Canvas supports keyboard pan/zoom via React Flow controls
- Inspector summarizes selection for screen-reader-adjacent review

## Do not

- Expect mutations from the canvas
- Treat fixtures as production inventory
