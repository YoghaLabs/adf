# Distribution

## Purpose

The Distribution Platform packages, releases, installs, and updates ADF artifacts.

It is separated from Package Manager (APM) and Marketplace:

| Layer | Role |
|-------|------|
| Registry / Marketplace | Catalog of installable packages |
| Package Manager | Install individual packages |
| Distribution | Release channels, bundles, updaters, offline/enterprise |
