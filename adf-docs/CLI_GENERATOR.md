# CLI Generator

## Commands

| Command | Role |
|---------|------|
| `adf init <name>` | Initialize a new project |
| `adf new <name>` | Alias of `init` |
| `adf generate <name>` | Generate with optional `--validate-only` |
| `adf doctor` | Health checks including template listing |

## Common flags

- `--destination` parent directory
- `--template` (default `foundation`)
- `--dry-run`
- `--overwrite`
- `--author` / `--project-version`
- `--root` ADF repo providing `adf-templates`
