# ADR Guide

## Why ADRs

Chat explanations vanish. ADRs keep architectural rationale in-repo for every future AI and human reviewer.

## Permanent Rule

From BUILD-003 through BUILD-020: **no architecture change without a new ADR**.

## How to Write One

1. Read `.adf/ADR_INDEX.md`
2. Create `.adf/adr/ADR-00N-Short-Title.md`
3. Fill all required sections
4. Update the index
5. Reference it from decisions/changelog when accepted

## Required Sections

Title · Status · Context · Decision · Consequences · Alternatives Considered · References · Future Impact
