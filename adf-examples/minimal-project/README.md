# minimal-project

Smallest oriented example layout for ADF evaluation.

## Goal

Provide a minimal checklist-shaped project a newcomer can scan in under two minutes.

## Layout

```text
minimal-project/
├── README.md
├── PROJECT.md
└── NOTES.md
```

## Try it

1. Read `PROJECT.md`  
2. Compare with `python -m adf dry-run sample --template generic`  
3. Create your own via `adf init`  

## Expected outcome

You understand that ADF projects are documentation- and structure-aware, not a single script.
