# Enterprise Demo Script

1. Install via `./install` or `.\install.ps1`  
2. `python -m adf doctor --root .`  
3. `python -m adf boot --root .`  
4. `python -m adf studio`  
5. Click **Enterprise** → point at governance foundations  
6. Click **Runtime** → point at observability panels  
7. Click **Visual** → show graph navigation  
8. Click **Marketplace** → show registry-oriented UI  
9. Close with Quick Start link: `adf-docs/quickstart/`  

Stop if asked for unsupervised multi-agent production control or live IdP — those are
not RC1 claims.
