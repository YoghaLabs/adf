# enterprise-demo

Enterprise-oriented **demo narrative** for ADF Studio and governance foundations.

## Goal

Give sales engineers and evaluators a storyboard for Enterprise Edition interest —
without claiming live production IdP SSO or autonomous agents (out of RC1).

## Demo script (≈5–10 minutes)

1. `python -m adf doctor --root <adf-root>`  
2. `python -m adf boot --root <adf-root>`  
3. `python -m adf studio`  
4. Studio → **Dashboard**  
5. **Enterprise** — show governance foundations UI  
6. **Runtime** — show monitoring panels  
7. **Visual** — open a graph view  
8. **Marketplace** — show package browsing UI  
9. State honestly: RC1 foundations vs roadmap hardening  

## Talking points

- Human remains decision maker  
- Orchestration is planning-oriented in RC1  
- Community evaluation path remains useful  
- Professional / Enterprise are commercial packaging (see Product Strategy)  

## Files

- `DEMO_SCRIPT.md` — click path  
- `TALKING_POINTS.md` — diligence language  

## Expected outcome

Evaluator understands enterprise direction without overclaiming GA Cloud or live SSO.
