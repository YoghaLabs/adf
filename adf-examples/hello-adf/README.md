# hello-adf

Minimal “hello” example for first-time ADF users.

## Goal

See a tiny, readable ADF-oriented sample and relate it to Quick Start.

## What this demonstrates

- A small project narrative for ADF newcomers  
- How examples live under the locked `adf-examples/` path  
- A starting point before `minimal-project` or `enterprise-demo`

## Try it

1. Read this README  
2. Follow `adf-docs/quickstart/FIRST_RUN.md`  
3. Optionally generate a sibling project:

```bash
python -m adf init hello-world --destination ../ --template generic
```

4. Open Studio (`python -m adf studio`) and browse Dashboard → Projects → Runtime  

## Expected outcome

You can explain what ADF is (framework + control center) and where to click next.
