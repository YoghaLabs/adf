# Release Packages — ADF v1.0.0-rc1

Logical packages for distribution. Physical archives are produced by release tooling; this folder is the **manifest SSOT** for what ships.

| Package | Contents | Path notes |
|---------|----------|------------|
| Core | `adf-core` runtime, engines, CLI entry | `packages/core/` |
| Studio | `adf-studio` desktop control center | `packages/studio/` |
| CLI | `adf` CLI surface | `packages/cli/` |
| SDK | Public SDK / service clients | `packages/sdk/` |
| Documentation | `adf-docs` freeze set | `packages/docs/` |
| Bootstrap | `bootstrap/` + `.adf` resume contracts | `packages/bootstrap/` |

See each subdirectory `PACKAGE.md`.
