# UI prompt

Use when changing Studio **UI primitives and interaction patterns**.

## Stack

React · TypeScript · Tailwind · shadcn-style primitives (`components/ui.tsx`) ·
Lucide · React Hook Form · Zod (forms validation only)

## Rules

- Accessibility: labels, focus rings, landmarks
- Theme via CSS tokens (`THEME_SYSTEM.md`) — Dark / Light / System
- No duplicated business logic in components
- Prefer modular components over page monoliths
